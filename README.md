# The-Magic-Music 轻量级音乐管理系统
这是一套基于 Spring Boot + Vue 开发的前后端分离音乐管理系统，完整覆盖从需求分析、架构设计、开发落地到性能优化、测试上线的全流程，适配主流浏览器与Windows环境。

## 技术栈
- 后端：Spring Boot、MyBatis、MySQL
- 前端：Vue、Element UI、Axios、Vue Router

## 核心功能
1.  双角色权限系统：普通用户端 + 管理员后台，权限隔离
2.  用户端核心功能：用户注册登录、音乐在线播放、模糊搜索、收藏、下载、评论、歌词同步、无缝切曲、个人信息管理
3.  管理员后台功能：歌曲/歌手/歌单/用户的全生命周期增删改查、批量操作、运营数据可视化统计
4.  性能优化：针对多表关联查询性能痛点，采用前缀索引+分步查询+Spring Cache热点缓存方案，将搜索响应时间从1s+优化至200ms以内，满足高并发场景需求
5.  安全防护：实现密码加盐哈希存储、防SQL注入、非法文件拦截等安全措施，保障系统数据安全

## 项目收获
完整掌握了前后端全栈开发的全流程，积累了从需求拆解、技术选型、架构设计到性能调优、测试验收的完整工程化经验，培养了严谨的逻辑思维、用户体验优化意识与问题解决能力。
